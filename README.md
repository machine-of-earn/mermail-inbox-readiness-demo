# mermail-inbox-readiness-demo

Demo video + assets for the `mermail-inbox-readiness` skill (Superteam Earn bounty
submission). The page at
https://machine-of-earn.github.io/mermail-inbox-readiness-demo/ plays the full 4:39 take
recorded against the live Mermail MCP server.

- `rehearsal/` — an offline MCP stand-in for the Mermail server, so the demonstrated
  workflow can be reproduced with no API key. See [rehearsal/README.md](rehearsal/README.md).
